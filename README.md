# กินอะไรดี (Kinaraidee)

เว็บแอปช่วยตัดสินใจว่าแต่ละมื้อควรกินอะไร โดยเน้นประสบการณ์ที่ง่ายมากสำหรับคนที่คิดไม่ออกว่า “กินอะไรดี”

## ฟีเจอร์ที่มีแล้ว

- ปุ่มหลัก “ไม่รู้เลย!” สำหรับเริ่มเลือกเมนูแบบง่ายที่สุด
- เลือกมื้อ: เช้า / กลางวัน / เย็น / ดึก
- เลือกงบต่อคน
- ระบุสิ่งที่ไม่อยากกิน เช่น เผ็ด เส้น ข้าว ของทอด ของหวาน หรือมื้อหนัก
- สุ่มเมนูตามเงื่อนไข
- มีฐานข้อมูลเมนูอาหารไทยและอาหารทั่วไปมากกว่า 30 เมนู
- กดเลือกใหม่ได้โดยพยายามไม่ซ้ำเมนูเดิม
- กด “ชอบ” และ “กินอันนี้” เพื่อบันทึกประวัติ
- แสดงสถิติเมนูที่เคยเลือกกินและเมนูที่ชอบ
- ค้นหาร้านที่มีเมนูนั้นผ่าน Google Maps
- แชร์เมนูให้เพื่อนได้
- เก็บข้อมูลประวัติไว้ในเครื่องผู้ใช้ด้วย localStorage
- รองรับหน้าจอมือถือเป็นหลัก

## สถานะโปรเจกต์

เวอร์ชันปัจจุบันเป็น MVP สำหรับทดสอบแนวคิดและ UX ก่อนพัฒนาระบบสมาชิก การสมัครรายเดือน ระบบร้านอาหาร และระบบรายได้จากพาร์ตเนอร์/affiliate ต่อไป

## Roadmap ต่อไป

1. ระบบสมาชิกและโปรไฟล์ผู้ใช้
2. แพ็กเกจ Free / Premium รายเดือน
3. ระบบตั้งค่าความชอบอาหารและข้อจำกัดส่วนตัว
4. ระบบแนะนำร้านอาหารใกล้ตัวแบบละเอียดขึ้น
5. ระบบพาร์ตเนอร์ร้านอาหาร / affiliate tracking
6. ระบบจัดอันดับเมนูจากพฤติกรรมผู้ใช้
7. ระบบ backend และฐานข้อมูลกลาง
8. ทำเป็น PWA / แอปมือถือ และเตรียมพร้อมสำหรับ Android/iOS
9. ระบบ analytics เพื่อดู funnel การใช้งาน
10. หน้าร้านค้า/แพ็กเกจสมาชิกและระบบชำระเงิน
